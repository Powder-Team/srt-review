# SRT 字幕审查 v1.2.0

使用网址：https://xuebicc102030-sys.github.io/srt-review/

通用字幕审查工具：上传 SRT → 上传对应的 TXT / MD / SRT 剧本 → 查看问题总览、确认修改 → 导出修订 SRT 或 ZIP。不接入 AI，文件在浏览器本地处理。

- 支持整个文件夹、多个 SRT、粘贴字幕和整批审查。
- 默认开始新任务，替换旧字幕，清除旧剧本和意见，恢复默认规则。可在更多选项中明确沿用自定义规则。
- 同一任务补充集数时选择“追加字幕”；默认不沿用旧剧本。
- “清空本次任务”可重新开始；清空与替换可在当前页面会话撤销。
- 当前任务自动暂存，刷新可继续；不同电脑和浏览器不自动同步。
- 备份、恢复和版本核对在页脚辅助入口中。

检查错词候选、跨屏重复、英文标点、词库中的品牌/IP和粗口。规则是确定性的文字检查，复杂语义和词库外名称仍需人工确认；0 项候选不代表全文无误。原文件保留，修订结果单独导出。

该仓库只包含静态网页，不包含真实字幕、剧本、工程备份或审查报告。
