# SRT 字幕审查

在线使用：https://xuebicc102030-sys.github.io/srt-review/?v=1.1.0

版本：1.1.0。纯浏览器本地规则检查，不接入 AI。

支持文件夹/多文件 SRT、TXT/MD/SRT 剧本、问题总览、编辑、SRT/ZIP/CSV 导出。字幕和剧本留在各自浏览器，不会上传到本仓库。

## 换电脑继续审查

1. 展开「跨电脑核对与迁移」。
2. 在原电脑「导出完整工程（换电脑）」。
3. 在新电脑「恢复完整工程」，选择同一个 JSON。
4. 点击「重新审查全部」。核对码、版本和筛选条件一致后比较结果。

完整工程包含字幕、剧本、规则、词库及采用/忽略记录。工程不会自动在多台电脑同步。需要再次迁移时重新导出最新完整工程。

相同名称、集数和原文的重复导入默认跳过；已有副本保留并提示。旧备份没有规则时会明确提醒。

## 检查更新

页面显示版本号并可检查更新。更新前自动保存工程；旧页可用上方带版本号的网址重新打开。

规则检查是辅助校对：疑似错词和需改写的残句仍须人工确认；零候选不代表全文无误。
