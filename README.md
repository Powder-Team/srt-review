# SRT 字幕审查 v1.5.0

网址：https://xuebicc102030-sys.github.io/srt-review/

规则检查 + AI 双轮复核，支持错词、跨屏、技术格式与粗口检查。默认 6 路并发，可调整为 1 / 3 / 6 / 12 / 24，限流时自动降速，每集完成立即展示并保存。

每位使用者在 AI 设置中填写自己的 API Key。密钥仅在当前页面内存保存，刷新或关闭后需重新填写，不进入工程、浏览器持久化存储或公开仓库。AI 直接连接使用者配置的网关；字幕及对应剧本会发送给该网关。

任务保存在当前浏览器，不跨电脑自动同步。可通过“备份 / 版本核对”导出、恢复完整工程。

这是静态发布仓库，仅包含网页构建产物。没有真实字幕、剧本、审查报告或任何 API Key。
