# SRT 字幕审查

纯本地文字规则审查工具，不接入 AI。支持字幕文件夹导入、本地剧本对照、整集/整批审查、问题总览、人工修订及 SRT/ZIP 导出。

使用地址：https://xuebicc102030-sys.github.io/srt-review/

## 使用

1. 导入 SRT 文件或整个字幕文件夹。
2. 关联本地 TXT、MD 或 SRT 剧本，选择关联范围。
3. 审查全部文件，在总览中查看错词、跨屏重复、标点、品牌/IP 和粗口候选。
4. 核对建议并保存修改，导出修订字幕。

字幕、剧本和工程保存在使用者自己的浏览器内，不上传到本仓库或其他服务器。不同使用者不会自动共享修改。规则候选需要人工核对；词库和文字匹配不保证覆盖全部语义问题。

## 备份与交接

“导出 SRT → 备份整个工程”生成工程 JSON；新浏览器或新网址可通过“恢复工程备份”读入，再按当前规则重审。自定义词库与规则设置请另行复制。清理浏览器数据前先备份。

## 发布

此仓库仅保存可部署的静态网页。GitHub Pages 从 main 分支根目录发布，资源使用相对路径。更新网页文件并提交后，Pages 会重新发布；不要将真实字幕、剧本或工程备份提交到仓库。
